## 第一部分：我内部的需求优先级（最重要，先看这个）

排课本质是"资源不够分"的问题，必然要有优先级。我把需求分成三层：

### 第0层：结构性约束（数学上不可违反，违反了课表就是错的）

这些不是"要求"，是课表成立的前提，无论如何都不会破：

1. 每个班每周正好排满26节（一二年级）或31节（三~六年级），一节不多一节不少
2. 每个班同一节课只能上一门课
3. 每门课的周课时数严格等于《教师与课程安排》里写的数字
4. 同一位老师不能在同一时间出现在两个班

### 第1层：硬性约束（求解器绝不违反，违反就直接报"无解"）

排在这一层的，宁可整个排课失败，也不会让它被破。当前有：

| # | 约束 | 备注 |
|---|---|---|
| H1 | 周二上午不排语文老师的课 | 教研时间 |
| H2 | 周三上午不排数学老师的课 | 教研时间（一二年级数学/综合实践第4节例外，见下） |
| H3 | 语文除周二外必须上午 | |
| H4 | 数学老师的课（含综合实践、劳动）除周三外必须上午 | |
| H5 | 班队活动固定周一下午第1节 | 授课人可被班主任列标注覆盖 |
| H6 | 三~六年级周五第3、4节必须语文连堂 | 一二年级降为软性(S3) |
| H7 | 一二年级语文连堂只能在周一/三/四且在上午 | 排不下周五时的退路 |
| H8 | 功能室冲突组组内不同一节课（限定年级） | 8组，2026-08更正过 |
| H9 | 15位老师周一上午2-4节禁排 | |
| H10 | 外语/音乐/美术/科学/道法同一天不出现2节 | |
| H11 | 体育每天最多1节 | |
| H12 | 语文老师连堂≤2节、每天总课时≤3节 | 按老师本人算，跨科目 |
| H13 | 数学老师连堂≤3节 | 按老师本人算，跨科目 |
| H14 | 其余专职老师连堂≤3节、每天总课时≤5节 | 按老师本人算，跨科目 |
| H15 | 每班数学系课程（数学+综合实践+劳动）下午≤2节 | |
| H16 | 跨校区（一年级B校区 vs 其余A校区）同一老师不相邻节次 | 课间赶不过去 |
| H17 | 卢诗雨除周二外必须上午 | 点名要求，覆盖她所有科目 |

### 第2层：软性约束（尽量满足，用权重决定"谁让谁"）

当资源不够、几条要求互相打架时，**权重高的赢，权重低的让**。这就是你问的"内部优先级"的核心：

| 权重 | 约束 | 让步含义 |
|---:|---|---|
| **50000** | 每天都要有一节数学老师的课 | 几乎当硬约束用 |
| **20000** | 每天都要有语文课 | 几乎当硬约束用 |
| **500** | 一二年级语文连堂优先排周五第3、4节 | 会为上面两条让步 |
| **300** | 每班数学系课程下午压到≤1节 | |
| **50** | 同校区跨年级同一老师课尽量错开 | 优先级较低，最常被牺牲 |
| **5** | 语文/数学/外语下午最多1节 | 最容易被牺牲 |

**举例说明这个权重怎么起作用**：如果"某个班周三有数学课"和"某位老师跨年级不相邻"这两条冲突了，
求解器会选择保住"周三有数学课"（50000），牺牲"不相邻"（50）——因为 50000 > 50。

### 为什么有些要求只能是软性的？

有两条你提的"硬性要求"，我实测发现**做成真正的硬约束会导致整个排课无解**，所以降级为超高权重的软约束：

- **"数学老师每天最起码一节课"**：二年级14个班里，7对班级两两共享同一个数学老师。每一对单独排都可行，但14个班放在一起时，数学老师这个资源整体不够分（周三上午还被教研占掉）。实测结果：做成硬约束 → `INFEASIBLE`（无解）。所以给了50000的超高权重，实际效果接近硬性，但保留极小弹性避免整体崩掉。
- 目前残留的未满足处，全部是"一个数学老师带该年级2个班"这种结构性资源冲突，不是算法没优化到位。

## 第三部分：目前已知的、无法100%满足的地方

这些不是bug，是数据本身的资源冲突，需要学校层面调整任课安排才能彻底解决：

1. **部分班级某天没有数学老师的课**：根因是"一个数学老师带该年级2个班"，加上周三上午被教研占掉，两个班抢同一个下午槎位。涉及的老师如张佳敏、杨璎馨、罗佳会、王雪薇、鲁倩、卢承袁、杜珊等。
2. **部分一二年级语文连堂没排在周五**：改排到了周一/三/四（仍是连堂、仍在上午），因为周五那两节被更高优先级的约束占用。
3. **同校区跨年级同一老师仍有相邻节次**：这条权重最低（50），是最先被牺牲的。
